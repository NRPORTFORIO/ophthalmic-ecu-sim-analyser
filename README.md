# Ophthalmic ECU Simulator & Medical Data Analyser

眼科医療機器（オートレフ等）の測定プロセスを想定した、C言語による組み込み制御シミュレータと、Pythonによるデータ解析・可視化ツールの連動システムです。
人の健康と安全に直結する医療機器開発において不可欠な「ノイズ（瞬き）処理」「フェイルセーフ（安全装置）」「診断サポートのためのデータ可視化」を具現化しました。

## 1. システム概要・アーキテクチャ

本プロジェクトは、医療機器内部の「制御（ハードウェア駆動・リアルタイム処理）」と、医師や患者が目にする「アプリケーション（データ解析・UI表示）」の2つのレイヤーを模擬しています。

---

## 2. 開発思想と実装した主要ロジック

### ① C言語： eye_ref_ecu_sim.c（組み込み・安全制御）
*   **リアルタイム性の模擬**：10msループ（100Hz周期）のタイマー割り込み制御を想定した構造。
*   **瞬き判定（デジタルフィルタ）**：測定中に患者が瞬きをした際、一時的に反射光（センサー値）が途絶える現象を検知。データをエラーとせず「瞬き（BLINK_HOLD）」と判定し、その区間の測定データ更新を自動で保留するロジックを実装。
*   **医療機器特有のフェイルセーフ**：万が一、システムの異常やバグによりレーザー出力（`laser_power`）が安全基準（`LASER_MAX_POWER`）を超えた場合、即座に「EMERGENCY STOP（出力ゼロ）」へ強制移行する安全設計。また、瞬き検知時には患者の目を保護するため自動で減光（セーフモード）する機能を搭載。

### ② Python： medical_data_analyser.py（データ解析・可視化）
*   **ノイズデータの自動パージ（Pandas）**：C言語側から出力された膨大なCSVデータから、瞬きフラグ（`BlinkFlag`）が立っている不正データを自動検出し、純粋な測定データのみを抽出して平均屈折度（Diopter）を算出。
*   **角膜形状トポグラフィの3D可視化（Matplotlib）**：算出された度数をベースに、乱視成分（角膜の歪み）をモデリングし、3次元のヒートマップ（3D Map）として可視化。医師の診断を直感的にサポートするUI表示を再現。

---

## 3. 技術スタック・使用ツール
*   **組み込みシミュレーション**：C言語 (GCC)
*   **データ解析・可視化**：Python 3.x
    *   `pandas` (データフィルタリング・統計処理)
    *   `numpy` (3次元モデリング演算)
    *   `matplotlib` (時系列トラッキングおよび3Dサーフェスプロット)

---

## 4. 実行方法

### 1. C言語の実行（ECUシミュレーション）
コンパイルを行い、プログラムを実行して測定ログ（CSV）を生成します。
```bash
gcc eye_ref_ecu_sim.c -o eye_ref_ecu_sim
./eye_ref_ecu_sim
```
*実行後、コンソールにリアルタイムログが表示され、同ディレクトリ内に `eye_measurement_log.csv` が生成されます。*

### 2. Pythonの実行（データ解析・可視化）
生成されたCSVを読み込み、データ解析と3Dグラフィックス描写を実行します。
```bash
pip install pandas numpy matplotlib
python medical_data_analyser.py
```
*実行後、コンソールに「確定平均屈折度」と「診断判定」のレポートが出力され、可視化されたグラフ画像（`cornea_analysis_result.png`）が保存・表示されます。*
