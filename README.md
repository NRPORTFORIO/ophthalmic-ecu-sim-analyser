# ophthalmic-ecu-sim-analyser
A prototype system for ophthalmic medical devices: C-based eye refraction measurement ECU simulator with noise reduction/fail-safe logics, and Python-based 3D corneal topography visualization tool. （日本語訳・参考）「眼科医療機器向けのプロトタイプシステム：ノイズ除去およびフェイルセーフロジックを搭載したC言語ベースの眼球屈折度測定ECUシミュレータ、およびPythonベースの3D角膜トポグラフィ可視化ツール。」
